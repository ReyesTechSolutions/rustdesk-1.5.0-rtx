=== CÓMO PUBLICAR ESTE REPOSITORIO (Reyes Tech Solutions) ===

Objetivo: https://github.com/ReyesTechSolutions/rustdesk-1.5.0-rtx
Esto completa la obligación AGPLv3 §13 (código fuente correspondiente a los
binarios que distribuyes). La app ya enlaza a esta URL en el diálogo About.

PASO 1 — Crear el repositorio en GitHub (vacío, SIN README ni licencia):
  1. Entra a github.com con la cuenta que usará la organización.
  2. Repositorio creado bajo la organización "ReyesTechSolutions" (Settings → Organizations → New)
     o crea el repo en tu cuenta personal y ajusta el nombre del remote.
  3. New repository:
     - Nombre: rustdesk-1.5.0-rtx
     - Visibilidad: Public
     - NO marques "Add a README", NI "Add .gitignore", NI "Choose a license"
       (el repo ya trae todo eso; si agregas algo ahí no podrás hacer push directo).

PASO 2 — Subir el código (desde C:\rustdesk-public):
  git push -u origin master
  git push origin v1.5.0-rtx

  (El submódulo libs/hbb_common ya está declarado en .gitmodules apuntando a
   https://github.com/rustdesk/hbb_common — GitHub lo mostrará como enlace
   automáticamente. NO necesitas subirlo tú.)

PASO 3 — Verificación (2 minutos):
  - Abre https://github.com/ReyesTechSolutions/rustdesk-1.5.0-rtx
  - Comprueba que se ven: REYES-TECH-FORK.md, LICENSE.txt, THIRD-PARTY-NOTICES.md,
    GUIA-COMPILACION-REYES-TECH.md y el enlace clickable a libs/hbb_common.
  - Comprueba que el About de tu instalador abre este repo ("Código fuente").

PASO 4 (opcional, recomendado) — Descripción del repo:
  "Distribución de escritorio remoto de Reyes Tech Solutions, basada en RustDesk
   1.5.0 (AGPLv3). Incluye fuente completo correspondiente a nuestros instaladores
   Windows 64-bit v1.5.0."

NOTAS:
- Si prefieres otro nombre de repo/organización, cambia también la URL en
  flutter/lib/desktop/pages/desktop_setting_page.dart (About → Código fuente)
  y en THIRD-PARTY-NOTICES.md, recompila y re-empaqueta.
- Para futuras versiones: sube el fuente ANTES de repartir binarios, y etiqueta
  (git tag) cada versión con el mismo número que el instalador.
